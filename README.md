# Testing Tienda UTNG

Proyecto de pruebas unitarias para una aplicación de gestión de productos.

## Tecnologías utilizadas

- Java
- Maven
- JUnit 5
- JaCoCo
- Git y GitHub

## Pruebas

El proyecto cuenta con pruebas unitarias desarrolladas con JUnit 5.

### Ejecución

Para ejecutar todas las pruebas:

```bash
mvn test
